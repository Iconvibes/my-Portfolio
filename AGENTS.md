# AGENTS.md

Instructions for AI coding assistants working in this repository.

## Contribution policy

- The repository owner is the sole author of all commits. AI assistants must
  **never** create commits, amend history, or push to any remote.
- Leave all changes in the working tree (staged or unstaged) for the owner to
  review and commit manually.
- Never add attribution trailers to commit messages — including
  `Co-Authored-By:` or `Co-authored-by:` lines — or any other line that
  credits an AI tool or agent.
- Never rewrite, rebase, squash, or force-push branch history.
