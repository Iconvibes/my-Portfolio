# Codeferd Digital

## Summary
A modern, enterprise-style marketing website for Codeferd Digital. Built with React and Vite to present services, selected work, and a clear path to contact.

## Tech Stack
- React (Vite)
- Tailwind CSS
- React Router
- Netlify static deployment

## Key Features
- Static prerendered pages for stronger SEO and faster first paint
- Modular content files for services, industries, insights, and case studies
- Reusable layout, section, and UI components for scalable growth
- Accessible responsive navigation and production contact form markup

## Local Development
1. Install dependencies:
   npm install
2. Start the dev server:
   npm run dev
